一、新增功能
1.Nacos 服务注册与发现
    - 应用启动时可选择注册到 Nacos 服务中心，实现服务实例管理。
    - 通过JVM启动参数-DNACOS_ENABLED=true控制是否启用，默认 false（本地独立运行）。
    - 支持使用 @LoadBalanced RestTemplate 进行服务间调用。

2. Nacos 动态配置管理
    - 应用启动时从 Nacos 配置中心拉取 order-system-jwt.yaml 配置文件。
    - 支持动态刷新配置项（如 message.system），无需重启应用即可切换消息系统（Kafka ↔ RocketMQ）。
    - 使用 @RefreshScope 实现 MessagePublisher Bean 的热替换。

二、使用说明
1. 本地独立运行（不依赖 Nacos）
java -jar order-system.jar
此时 -DNACOS_ENABLED=false，应用使用本地 application.yml 中的配置。

2. 启用 Nacos 模式
前提：请使用nacos-start命令将nacos服务器启动起来；启动日志在该目录下：
tail -f /Users/allen/ai-infra/nacos/standalone/nacos-3.2.1-2026.03.30/logs/startup.log

java -DNACOS_ENABLED=true -jar order-system.jar
应用会连接到 Nacos（localhost:8848），会先加载新的bootstrap.yml配置，后面再拉取远程配置，并将本服务注册到服务中心。
