[druid最重要的两个组件]
两个组件各司其职

- WebStatFilter (数据采集器)：它的任务是收集原始数据，特别是Web 请求和数据库访问的关联数据（例如一个 HTTP 请求触发了哪些 SQL、执行耗时等）。
没有它，监控页面就会缺少核心的 "Web 应用"、"URI 监控" 和 "SQL 监控" 等模块的关键数据。
- StatViewServlet (数据展示器)：它提供了一个可视化仪表盘，将 WebStatFilter 和 StatFilter 收集到的数据，
以 HTML 页面的形式直观地展示出来。没有它，你就无法通过浏览器便捷地查看和分析监控数据。

因此，可以这样理解它们的协作流程：
- WebStatFilter 默默地在后台收集数据。
- StatViewServlet 读取这些数据并将其渲染成你可以在浏览器中看到的监控页面。

补充说明：除了 WebStatFilter，还有一个 StatFilter 负责收集 SQL 执行、连接池使用情况等基础统计数据。filters: stat,wall 配置中的 stat 指的就是它，通常也会一并开启。
